Technical conventions
---------------------
- All incident, system and symbol SVG files use viewBox="0 0 64 64".
- Transparent canvas; no white card or baked background rectangle.
- No glow, shadow, external image, embedded raster, base64 content or SVG filters.
- Common line width: 2.4 units for interface icons.
- Rounded line caps and joins for a consistent family.
- Hexagon frames are outline-only and their inner surfaces are transparent.
- Full logo lettering is converted to vector paths and has no external font dependency.
- SVG 1.1 compatible and suitable for Qt SVG / PySide6 / QML usage.
